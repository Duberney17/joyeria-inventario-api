# API Joyería - Inventario

CRUD de productos (joyas) para gestión de inventario.

## Tech stack
Node.js, Express, MongoDB Atlas

## Instalación
1. Clonar repo
2. npm install
3. Crear .env con DATABASE_URL
4. npm run dev

## Endpoints
GET /api/jewels
POST /api/jewels
GET /api/jewels/:id
PUT /api/jewels/:id
DELETE /api/jewels/:id
